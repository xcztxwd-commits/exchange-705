# 体验金账户管理与交易提示

交易区在选中体验金时显示常驻提示，并在手机确认页再次说明资金来源；切换账户后提示消失。PC、标准手机和高级界面支持19种语言，后台关闭账户时的交易错误也按当前语言显示。

后台「用户管理 → 操作 → 体验金账户」可开启/关闭体验金交易、设置可用余额和查看占用金额及各批次到期时间。沿用修改余额权限，服务端只允许超级管理员及有写权限的总控访问；模拟账户入口不提供此操作。关闭保留本金及已有持仓，结算和退出仍可执行。增加本金创建1天有效期的新批次，减少本金按到期顺序回收可用部分，不修改占用金额、现金账户和既有利润。

调整包含账户版本、明确确认、当前会话绑定的持久请求编号及审计。重复请求仅返回当前状态；迟到重试不覆盖之后的修改。账户、批次、流水、回执与审计在同一事务提交，冲突或审计失败全部回滚。金额以字符串传输并使用 Decimal 计算，支持16位小数。

增量结构仅为 `trial_account.enabled`，旧记录默认开启。上线前备份并在不同物理 MySQL 实例恢复核对，先应用审核后的增量结构，再更新应用。现有有效批次中，无到期时间或到期时间晚于执行时刻三天的批次，单次调整为执行时刻后一天；已过期、已失效及其余短期批次不延长。执行记录和逐批前后值保存在服务器私有发布目录，回退只恢复目标期限字段，不用旧备份覆盖新发生的业务金额。

验证：独立 MySQL 50项相关测试通过，无失败/跳过，涵盖 HTTP 绑定、精确金额、并发/重试、关闭后的持仓退出、到期、权限/租户隔离、审计失败回滚及相邻资金锁/写入检查。前端既有资金来源和会话测试15项通过。本地浏览器验证三种交易界面的19语言、账户切换、确认页、窄屏及深浅色；后台验证保存确认、响应丢失后的刷新恢复和原请求重试、非法金额及手机布局。未以夹具结果冒充线上验收；最终发布与线上复验另附记录。
