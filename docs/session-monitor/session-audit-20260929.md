## 需要用户处理，而不是替开发做测试

1. 业务规则确认：贷款应允许余额直接还款，还是合同禁止余额扣款？当前报告指出合同描述与LoanService实现冲突。请提供应遵循的正式规则；不得由翻译人员自行改变债务义务。
2. 产品边界确认：期限交易的正式产品定义、同价结算及预设盈亏是否严格仅用于明确标识的测试/模拟账户。研发可审计隔离与权限，不能自行替产品作合同承诺。
3. 平台拦截：历史失败记录是真实的，现有证据核对不等于被拦操作已恢复。无需关闭防护、交密码或改业务权限；若需恢复该受阻执行，请通过平台正常支持/访问流程处理。其他独立项目不等待它。
4. 正式部署不在本调度当前授权内；本地隔离测试、修复和Git验收无需再次批准。真实运行环境验收若必要，再明确环境/数据/写入范围，不要求真实客户账户试单。
5. Deriv/Yahoo双源属于设计成果；仅在决定实施时确认数据许可、产品映射和规格，不把它列为本轮必做新功能。
