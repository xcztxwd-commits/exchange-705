最新展示规则：按用户确认，缺失历史在前端补零，从窗口最左侧画到底部并在首次记录处升起。原始快照、余额和收益不改写；点击补零区域注明展示补零。如果补零构成高低点，极值标签也标注“补零”。此规则覆盖下文早期版本关于留空的说明。

- 纵轴及极值：固定四档等距金额，顶档向上取整为易读金额（例如 243,541.37 对应 0 / 100,000 / 200,000 / 300,000）；正余额从零开始。高低点来自完整窗口的原始快照与当前余额，接口额外保留极值，避免降采样吞掉峰谷。最高最低相同则合并标记。
- 零余额：全宽淡虚线是零参考线，不是历史余额；实际有记录的零余额沿底部实线绘制，阶梯线在实际变动时刻升起。不填造缺失历史。若窗口开始前两分钟内有已知余额，可保持至窗口起点，并用 observedAt 保留原采样时间。

- 页面：移动端 `/profile`。保留原菜单和底部导航；只有标题进入资产详情，图表点击不再误跳页。
- 数据：`GET /api/user/asset-history?range=1D|1W|1M|1Y`，仅从认证身份取用户，不接受目标用户 ID。
- 口径：FUND + CONTRACT + OPTION 的 available + frozen；不含未实现浮动盈亏、理财持仓、借贷负债。资产变动不是投资收益，入出金也会影响曲线。
- 同步：可见页面每 10 秒读取当前余额，窗口重新聚焦时立即更新；顶部金额和曲线末点使用同一响应。失败保留旧值并标记同步失败，首次失败不展示虚构余额。
- 历史：后台每分钟持久化真实账户快照，保留 370 天；跨账户转账和冻结不会造成虚假资金损益。上线前没有快照的区间不伪造，不倒推历史。
- 图表周期：固定滚动最近 24 小时/7 天/30 天/365 天，接口返回精确 from/asOf；横轴始终覆盖完整窗口，标明起始和现在的日期时间。粒度分别为 1 分钟/1 小时/4 小时/2 天，各时间桶取最后一个真实快照，保留首条真实记录。
- 收益周期：继续按系统配置时区的自然日、本周（周一开始）、本月、本年统计，页面注明与图表滚动窗口的区别。收益文案随周期切换为今日/本周/本月/本年收益。
- 收益：汇总已平仓期权盈亏、已平仓合约净盈亏（新单扣实际手续费，旧单遵从原退款规则）、已发放理财收益；不把充值、提现、转账或后台调余额算成收益。不使用资产快照差额冒充收益，没有可靠期初本金时不展示收益率。
- 曲线：1 日最多约 1442 点，其他周期约 170–185 点；统一 68 列像素用于显示，点击按实际时间查询所选周期的数据。没有历史或数据缺口超过一个采样桶＋2 分钟时留空，不把近期数据拉满完整窗口、不以零补缺、不增加虚构振荡。并非逐笔账务审计曲线，分钟内短暂变动可能未被采样。
- 动效：首次载入、手动刷新、周期切换、余额变化触发；轻触图表从触点展开。尊重减少动态效果设置，页面离开时清理定时器和动画。
