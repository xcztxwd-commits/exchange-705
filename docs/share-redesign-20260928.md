- 全部模板重新排版为 1080 × 1440：品牌与品种在上方，盈亏和收益率居中占据主要区域，价格、真实行情及结算说明在下方。保留各模板的配色、无文字背景和装饰主题。
- 所有绘制路径彻底移除保证金、投入金额、手续费、订单编号。即使旧调用方传入 `capital/fee/orderId: true`，也不会绘制这些字段。

- 正值绿色、负值红色、零值及不可用值灰色；方向标签不再借用盈亏颜色。

- 无法计算收益率时，用盈亏作为重心；只显示收益率的直接渲染请求使用破折号，不伪造 0%。

## 后台配置

“分享图展示重心”可选择“盈亏为重心”或“收益率为重心”，应用于全部启用模板。选择后后台预览立即刷新，保存后用户下次打开分享弹窗生效。

沿用 `share.templates` 原子保存，版本 2 增加可选字段：

```json
{"version":2,"focus":"rate","templates":[{"id":"light","languages":["*"]}]}
```

- `focus` 仅接受 `amount` / `rate`；缺省为 `amount`。
- 旧 CSV 和未带 `focus` 的版本 2 配置继续可用。
- `GET /api/user/share-templates?locale=ja` 保持旧数组响应。
- 新客户端使用 `GET /api/user/share-templates?locale=ja&details=true`，返回 `{ "templates": [...], "focus": "rate" }`。
- 保留语言范围、模板排序、默认模板及完整语言覆盖检查。未修改数据库结构或实际配置值。
- 发布时先更新后端，再发布后台及两个前端；旧后端不会接受带新字段的配置。

## 文案审核

删除所有装饰性、语义不明确的单词标题，包括 WORLD / FOCUS / EXECUTION 及各语言对应的“世界 / 专注 / 执行”；日语的“世界 / 集中 / 実行”也完全移除。不用新的收益承诺代替。

图片仅保留交易记录、实际指标、成交价格、行情来源、结算依据与未来收益风险说明。其他语言的泛化“回顾 / REVIEW”行情标签改成明确的近期市场蜡烛图说明，收益率使用回报率术语而非仅指正利润的标签。

### 日语重点核查

- 已实现盈亏：`実現損益`。与 [DMM FX 官方术语定义](https://fx.dmm.com/support/gloss/detail/2219/) 对齐，表示平仓后实际产生的损益，而不是未实现损益。
- 收益率：`収益率`。使用回报率表达，不添加年化、胜率或保证金字样；[SMBC 日兴证券术语](https://www.smbcnikko.co.jp/terms/japan/ha/J0099.html) 使用该术语描述投资表现。这里仍是单笔收益率，绝非年度收益率。
- 开仓/平仓成交价格：`新規約定価格` / `決済約定価格`；时间对应 `新規約定日時` / `決済約定日時`。参考 [GMO 外货官方损益计算说明](https://faq.gaikaex.com/faq/show/332?site_domain=default) 使用的新规/决算约定术语；产品还覆盖非外汇品种，所以采用通用“価格”，而不是只针对汇率的“レート”。
- 结算依据：`決済記録に基づく損益`，补齐原来省略的宾语。
- 模板名改为 `取引明細`、`取引履歴`、`ゴールドチャート`、`ホワイトチャート`、`ダークチャート`；不使用不自然的“原版”或含糊的“プロレビュー”。
- 保留 `個別の取引記録 · 将来の収益を保証しません`，明确不是未来收益承诺。上述术语校对不等同于日本监管合规认证。
