四、不可擅自更改的已确认要求
1. 同一套程序、共享数据库、tenant_id 字段软隔离。当前全部历史业务数据归默认租户；前台用户邮箱/手机号允许跨租户重复，资金、密码、实名、订单、配置独立。
2. 每租户仅一个总控分配的前台子域名，换域名归属不变。总控独立后台；租户共用现有后台地址，登录只输入账号密码，不输入租户编号。后台登录名全局唯一；处理管理员与代理的身份歧义，允许总控和租户负责人创建范围内的后台账号。
3. 总控业务监管页只读。总控一键进入指定租户后台后直接具有该租户超级管理员级业务写权限，不得擅自改为只能查看或必须另切维护模式。可在租户范围内实施配置、账号、审核和带流水的资金管理，保留确认、事务、并发、幂等及安全验证。
4. 一键进入使用真实总控的限时访问会话，显示“总控管理”，不创建隐藏租户管理员、不占管理员列表、不挤掉租户登录、不发送进入通知。总控专用审计不向租户展示，但真实操作者、访问及修改必须留痕；不伪造租户人员操作、不抹除资金流水、不修改或删除审计证据。不承诺业务变化不会被租户察觉。
5. 多租户同时打开的标签页不能串令牌、状态和请求对象。一次性票据、会话撤销、过期、来源与目标租户校验都需实现。
6. 总控控制功能授权和锁定配置，可强制站内客服、禁止外部客服。租户独立配置品牌、币种、产品、资金渠道、邮件短信、人员等；原始公共行情源可共享，私有配置和缓存不能共享。
7. 关闭功能禁止新增，但保留已有订单结算、查询及必要资金退出；租户停用不删除数据或静默丢弃结算责任。
8. 在线人数按最近五分钟有效活动真实用户统计；每个租户后台可点击明细，总控可看各租户明细，显示最近查看页面及时间。白名单页面标识，不采集敏感 URL 参数，不伪造实时浏览事实，模拟账号不重复计数。
9. 站内客服会话、排队、转接、附件、站内信全部租户隔离；总控与本租户负责人按设计监督。留存默认一年，具备自动清理能力但初始关闭，测试期间不得自动删除；支持保全及清理审计。
