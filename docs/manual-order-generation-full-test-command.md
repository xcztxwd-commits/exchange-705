## A. 固定条件组合矩阵

固定维度为七个：目标净收益、开仓分钟、平仓分钟、方向、杠杆、手数、仓位比例。用户、品种、时区是必需上下文。

1. 程序化枚举七维的全部 128 个固定/不固定组合，包括全不固定、仅净收益、收益加开仓、收益加平仓、全固定。每个组合记录输入、预期、实际、断言和用例 ID，不是只生成一份组合清单。
2. 用具有已知合法解的确定性行情与账户夹具构造组合；通过独立公式检查价格、方向、手数、保证金、手续费、净收益与比例，不能调用被测求解器生成预期再与自己比较。固定数值精度、比例量化误差必须符合文档。
3. 对关键多条件组合构造冲突和无解案例。已知可行解却被拒绝是待修复缺陷，不得把所有异常都当作预期通过。区分固定条件矛盾、数据缺失、可行但搜索未发现、收益超差。
4. 默认方向和杠杆不得偷偷固定；生成值不自动成为约束；逐一取消固定、取消全部固定、重新输入、再次生成、清空输入都验证。
5. 特别检查固定比例＋杠杆＋收益、固定手数＋比例、仅比例、手数＋收益＋一端时间、双端时间＋全部数值，以及多次切换驱动后固定值和实际提交是否一致。

## B. 数值、时间、行情与真实性

- 收益：正、负、零、极小、极大；恰好 ±5%、略内/略外；负目标使用绝对值分母，零目标精确匹配。超差明确报错，不改目标、不伪造行情/利润、不创建订单。
- 手数 0.01 步长边界、取整到零、错误符号、非法精度、溢出、非有限输入；余额正/零/负；仓位小于、等于、大于 100% 及 120%；杠杆小数与超过普通限制。保证金、费用只计算一次，固定手数时盈亏不重复乘杠杆。
- 时间：不固定、一端固定、两端固定、同分钟、逆序、当前未结束分钟、未来、七天窗口边界、跨日/月、UTC、亚洲时区、纽约/伦敦夏令时不存在和重复时刻。
- 行情：实际配置的加密、股票/指数、外汇等可用类别；休市、缺分钟、部分数据、空数据、缺换算率、超时、加载中、缓存复用与最终预览行情变化。缺数据不得借邻近价或当前价伪造。
- 使用固定随机种子和多个种子重复验证小时级软偏好；构造长短持仓都可行的同条件行情，记录时长分布和选择理由。短持仓明确固定时允许；不要为“看起来真实”加未经确认的硬性时长限制。检查近似收益与真实性的权重，不只测 score 函数而不测最终选单。
- 用固定种子的有界随机/属性测试补充组合矩阵。检查所有成功结果的约束、收益容差、时间顺序及真实候选来源；保留可复现种子。不要写无限循环或进行无界外部行情扫库。
