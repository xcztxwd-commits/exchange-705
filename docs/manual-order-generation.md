# 手动模拟单：约束联动与一键生成

## 需求解释（2026-09-28）

这是既有带手动标记的模拟单生成器，不是真实交易预测。选择用户、品种和时区后，可以只填写净收益，也可以同时填写任意开/平仓分钟、方向、杠杆、手数或仓位比例。填写的字段作为生成约束，清空即交给生成器；没有固定选择框。自动结果显示在输入框外，不自动成为约束；方向、杠杆等初始为空。

生成只查询历史行情、计算和预览，不创建订单、不改钱包、不改权益。仍需点击既有确认创建按钮，沿用原有权限、净收益、开关联动、事务及手动标签。

目标净收益采用相对误差：abs(实际净收益－目标净收益)/abs(目标净收益) <= 5%，包含边界；负收益同样处理。目标为 0 必须实际为 0，不把百分比除零。误差超出时提示范围内最接近结果，不能悄悄改目标或自动创建。价格、手续费和手数步长保持真实规则，不改利润字段凑数。

已填写字段不被生成器覆盖。手数精确遵守 0.01 步长；仓位比例受手数/杠杆精度影响允许最多 0.01 个百分点的量化差，显示实际值。条件冲突时明确报错。无法计算比例的非正余额不允许填写比例，仍允许其他输入。

## 搜索与真实性偏好

未固定时间时搜索最近七天；只固定一端时在该端前/后最多七天搜索，不能生成未来时刻。两端都固定时直接验证。生成接口统一只使用已结束分钟。范围有界且在结果中明示，不声称穷尽全部历史。仅使用系统现有历史行情链路返回的有效分钟 open 及对应换算率，缺数据不造价；该链路可能包含系统已有的历史价格配置，不能把结果宣称为未经处理的外部市场成交记录。

候选优先小时级持仓（约 2–12 小时），兼顾 1–3 天；几分钟持仓给极高惩罚，不设不可突破的统一最小时长。用户固定的时间必须尊重；短时数据只能作为低优先级候选，并给出提示。自然仓位和适中杠杆有更高权重，但不禁止已允许的超额仓位。少量随机扰动让同样约束下有变化，不能以随机替代收益校验。最终必须再次走权威预览，复查约束与误差。

## 实施边界

增加独立、有界的纯计算候选选择器；行情批量读取复用现有窗口缓存；后台新增 generate API 后接回原 preview/create。UI 固定条件与显示计算分开，生成过程中防止旧请求覆盖新表单。无需数据库迁移，不改普通订单、钱包和权益归集业务。

## 验收

填写比例和杠杆时先据此求手数，再检查目标收益的 ±5% 容差；不能为了更贴近收益而覆盖比例。普通重新预览如果与仍填写的手数或比例冲突，页面提示并禁止确认，须重新生成或清空冲突条件。

覆盖仅净收益、收益加开仓时间、只固定平仓、固定手数/比例/方向/杠杆及组合冲突；正负/零目标、5%边界和超界；真实时长偏好与短时回退；分钟/时区/未来校验；后台构建和浏览器生成后确认流程。算法测试不代替实际生成 API 与浏览器验证。结果必须保留手动来源，未实际运行的测试不得写成通过。
