# 日语双端全页面二次审校

日期：2026-09-27。范围：当前移动端及 PC 前台；不包含独立中文管理后台。参考用语沿用 [机构资料与语义依据](terminology-sources.md)，本轮按实际页面、字段、计算量纲和操作结果重新组织日语句子，不把“查不到官方原句”当作不翻译的理由。

## 本轮交付

- 双端各修正 **84 个日文字典值**，见 [本轮新旧对照](ja-second-pass-changes.json)。累计相对最初盘点修正 544 个日文字典值。
- 日语集中 UI 目录从 273 条增至 **322 条**，新增 49 条，另修订若干原有文案。补充 **82 条精确后端消息、19 类错误前缀**及受限数字消息的日语处理；不模糊匹配、不丢弃未知诊断内容。
- BBI、BRAR、CR 保留英文名称和缩写；参数标签、设置说明、错误提示仍使用日语。`期限取引` 作为依本系统规则拟定的描述性名称保留，不冒称日本交易所官方产品名称。
- 修复 PC 身份审核、出金账户缺失、申购上下限、平仓/撤单确认、中途解约、资金振替等中文顺序拼句。现在完整句子可以按日语词序插入金额、比率和交易代码。
- 修复移动端资产图的英文标题、收益周期、加载/失败/隐藏状态、键盘操作说明及 Canvas 标注；切换语言会重绘。补齐加载/成功弹窗、行情来源警告、Logo、图片说明等路径。
- 补齐 Element Plus 日语语言包中实际仍为英文的关闭按钮、数值增减、滑块等辅助标签。图表参数辅助标签也改为日语。K 线 `1m` 等显示为 `1分`，避免大写 `1M` 的分钟/月歧义；接口周期代码不变。
- 日语借款合同不再强行把一个完整姓名拆成姓、名，也不再用虚构姓名、美国地址和电话号码填补缺失资料。修复合同金额、利率、期限、到期偿还、延滞条款的拼句。
- 发现并修复两个量纲问题：借款接口中的 `dailyRate = 0.18` 已表示 **0.18%**，原移动合同重复乘以 100；申购确认和收益订单中 `dailyYield` 是金额，不能使用“日收益率”标签。只修展示，未改变利息、收益或订单结算计算。
- 合同日期的时区标签改用系统时区，避免时间按 UTC 显示却标成 BST。公告请求增加语言一致性检查，旧语言的延迟响应不会覆盖新语言；默认公告不再固定英文。

## 边界与仍需提供的内容

- **后台动态内容**：公告正文、商品名称/说明、人工审核备注和第三方客服页面不等于前端固定文案。本轮使用日语夹具验证显示，不能证明生产数据库中的每一条记录都有日语版本；没有擅自猜译、隐藏或重写这些业务数据。需要后台实际日语内容才能验收该部分。
- **未知后端诊断**仍保留原文；已识别的错误前缀和已知原因会本地化。这是为了保留真实故障信息，不把未知原因换成不相干的日语提示。
- **借款条款原意矛盾**仍需业务确认：原文一处要求出金前偿还且不可直接扣账，另一个提前还款流程则自动扣账户余额。已改善日语表达，但没有用翻译暗改权利义务，也不对原文的司法辖区/法律效力陈述作保证。
- 本轮完成的是当前前台路由与上述状态的第二次日语修复和验证，**不是“任何动态内容、任意状态都绝无歧义”的保证，也不是外部母语审校人员或参考机构的认证**。其他语言未在本轮做同等逐句修复。
