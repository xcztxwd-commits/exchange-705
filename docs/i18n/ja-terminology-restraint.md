# 日语术语保留与过度翻译修正

日期：2026-09-27。本轮沿用用户确认的原则：代码、品牌、专有名称保持稳定；成熟日语术语正常本地化；没有可靠对应的指标名称保留英文；解释与操作句子使用日语。

## 本轮定点修改

两端 `src/store/uiMessages.ts` 同步修改四项，不改指标算法、内部代码、参数、接口和交易逻辑。

|项目|修改前|修改后|原因|
|---|---|---|---|
|TRIX|三重指数平滑移動平均（TRIX）|TRIX（トリックス）|避免把变化率振荡指标误解成移动平均线本身；采用 TradingView 日语名称|
|PVT|価格・出来高トレンド（PVT）|PVT（プライス・ボリューム・トレンド）|采用已有平台使用的名称，而非自行逐词意译|
|PIXEL FLOW|ピクセル表示|PIXEL FLOW|按固定界面名称保守保留英文，不宣称它已注册为品牌；附近操作说明仍为日语|
|SMA 说明|平滑移動平均線|平滑移動平均線（期間・重み指定。単純移動平均線とは異なります）|保留内部 SMA 代码，说明本实现不是通常的简单移动平均；不擅改为 SMMA 或改变算法|

SMA 的判断来自已安装的 KLineCharts 10.0.0-beta3：参数为 `[12, 2]`，后续值按 `(close * weight + previous * (period - weight + 1)) / (period + 1)` 递推。这不能仅凭名称认定与其他平台的 SMA/SMMA 算法相同。

## 保留，不为“统一英文”反向过度修改

- 26 项指标代码保持原样。MA、EMA、MACD、RSI、CCI 等标题/图例继续显示代码，描述可以使用成熟日语名称。
- 移動平均線、ボリンジャーバンド、商品チャネル指数、相対力指数等有平台资料支持，不恢复成整段英文。
- BBI、BRAR、CR 继续使用英文描述与缩写；这些英文描述也不代表全球唯一官方全称。
- 页面中的 USD、XAUUSD、TRC20、SWIFT、UID、UTC、FOREX EXCHANGE 保留；地址、邮箱、账号、订单编号、用户输入和动态交易代码不翻译。
- 绑定数字资产页面保留 Bitcoin、Ethereum、Tether、USD Coin 及 BTC、ETH、USDT、USDC、ERC20、TRC20。
- IANA 时区标识和语言选择页的语言自称保留，不作为日语漏翻。
- `1分`、`1時間` 和完整操作/错误句子保留日语，不因允许术语英文而回退正常本地化。
