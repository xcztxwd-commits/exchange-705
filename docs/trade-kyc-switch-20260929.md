# 交易实名总开关（非租户版）

- 配置键：`trade.kyc.required`。默认 `true`，仅接受 `true` / `false`；后台“设置”页面可修改。该配置对全站生效，不按租户区分。
- 开启时，服务端拒绝未审核通过用户发起的合约、期权以及理财购买/赎回写操作，返回既有 KYC 错误；行情读取、历史与自动结算不受影响。关闭时不改变实名认证资料或审核状态，只放行上述交易准入检查。
- 手机与桌面端下单前预检；需要认证时跳转认证页面，PC 打开用户中心认证面板。HTTP 403 的 KYC 错误亦会跳转，但不会自动重放订单。服务端仍是最终判定。
- 体验金不绕过开关；开关恢复后，未通过实名的用户重新受到限制。
- 验证：运行后端 `TradeKycSwitchTest` 与三端生产构建；改配置前保留原值，回退时在后台恢复原值。
