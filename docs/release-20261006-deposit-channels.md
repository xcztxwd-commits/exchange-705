# 2026-10-06 入金渠道展示更新

## 变更范围
PC 入金面板、普通版/高级版手机入金页及旧版 PC 入金页复用一致规则，依据现有租户启用设置选择展示渠道：
- 仅启用银行卡：显示银行卡内容，不显示渠道切换。
- 仅启用虚拟币：显示虚拟币内容，不显示渠道切换。
- 两种均启用：显示渠道切换，默认虚拟币，保留用户选择。
- 两种均未启用：默认银行渠道及联系客服，不显示渠道切换或付款提交表单。

后端收款配置、权限、资金入账和审核逻辑不变；本次没有数据库迁移。

## 验证
7 项定向测试、PC/手机两端生产构建通过。模拟 API 的浏览器检查覆盖 PC、普通手机及高级手机各 4 种渠道组合（12 组），包括双渠道切换、无配置客服兜底，未进行业务写入。另检查生产 Tailwind 布局类及自动手机模式入口，避免此前构建遗漏再次出现。

## 发布与回退边界
仅增量更新 PC/手机应用镜像，保留现有配置、旧哈希资源和旧镜像。发布前保存现有 Compose 配置；切换后检查健康、完整资源 SHA-256 和公开入口。数据库、Redis、后台、总控、后端及上传不更新。回退仅恢复本次备份的 PC/手机镜像配置，不恢复数据库或删除数据卷。实际线上结果与回退位置保存在本地 rollback/deposit-channel-visibility-20261006 发布材料，不提交密钥或运行配置。
