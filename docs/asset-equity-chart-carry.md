# 资金曲线：仅显示层无限期沿用历史值

缺失采样、长间隔或无法估值的点，仅在图表展示时沿用最近一条更早的有效值；没有 30 分钟或周期长度限制。真实零和负值均为有效值。后续真实观察出现后立即采用新值。

窗口之前的最后一个有效分钟观察由 API 的独立 carryIn 字段提供，保留其原始 observed_at；仅用于窗口左端延续。查询限制当前用户、net_equity_v1 口径和 observed_at < from，不读取其他用户或未来点，不生成当前周期草稿。

折线采用阶梯延续，像素列与长按金额使用同一规则。长按显示沿用提示和来源日期时间。没有任何更早有效数据时留空，不反向使用未来点、不补零。

carryIn 不加入 points、OHLC、极值、样本数、收益或真实缺失区间。原始 NULL 和实时 total 保持不变；实时估值不可用提示保留，历史沿用不能冒充当前真实权益。未写入任何补点记录。

验证：前端 assetPixelWindow、assetEquityHistory、assetCarryForward 测试及构建；后端 AssetEquityCarryTest 校验跨窗口、无时间上限、零值、空值、用户/版本隔离与只读。
