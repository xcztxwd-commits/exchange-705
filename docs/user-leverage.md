# 用户自选杠杆

合约下单通过滑块拖动选择 1–100 的整数倍杠杆，也可点击 1、2、5、10、20、25、50、75、100 倍及后台指定品种上限的快捷按钮，默认 100 倍。拖动时倍数与预估保证金实时更新，滑块支持键盘方向键调整。API 接受 1–100 的整数，并校验品种上限；后台降低上限后，默认值随上限降低。未传 leverage 的旧客户端也使用新规则。期限订单不变。

新订单的计算口径：

- 持仓数量 = 手数 × 每手数量；每手数量与所选杠杆保存为订单快照。
- 保证金 = 持仓数量 × 开仓价 ÷ 杠杆，向上保留 16 位小数。
- 买入盈亏 =（平仓价 − 开仓价）× 持仓数量；卖出方向相反。相同持仓数量的盈亏不重复乘杠杆。
- 手续费 = 手数 × 后台手续费倍数。下单冻结保证金与手续费；成交后平仓只返还保证金并结算盈亏，收取一次已预留手续费；未成交撤单全额退回。
- 市价开仓和平仓仅使用服务端新鲜行情。限价单先按限价预留，成交时按实际价格调整保证金；补缴金额不足则继续等待。
- 沿用账户级强平。可用余额加持仓保证金及浮动盈亏不大于零时触发；新单手续费不计入可抵亏权益，挂单冻结资金不被清零。

例如 0.01 手、每手 1000 单位、开仓价 100：100 倍保证金 10，20 倍保证金 50；买入后价格升至 101，两者交易盈亏均为 10，另计手续费。金额沿用项目现有结算单位，本次没有新增汇率换算。

发布前应用 `exchange-backend/src/main/resources/db/manual/705-user-leverage.sql` 中尚不存在的两列；当前 `ddl-auto=update` 也会新增它们。前后端应同步发布。`contract_order.lot_size` 的历史 NULL 不可回填：它标识旧订单，旧单继续使用原杠杆盈亏及手续费退款规则，不重算余额。`trading_symbol.max_leverage` 的 NULL 表示 100 倍，原 `leverage` 字段保留兼容。
