# 最新非租户版本发布范围

基线：90a8f06。源代码在独立工作树整合，本地租户工作区不作为构建上下文。

## 本次纳入
- 三端订单分享模板重新设计，含多语言术语、尺寸、布局及后台模板名称。
- 活动可视化模板编辑器（GrapesJS 开源核心与许可证）、结构化设计校验、PC/移动渲染；旧活动保持旧展示，不覆盖线上已有设计。
- 活动/模板分离、收件人检索、自动投递设置、未读重复提醒、软删除与全局弹窗。自动发送默认关闭；用户余额和真实到账仍由既有后端控制。
- 客服多语言回复、站内信接收人搜索、模拟环境音频地址修复、模拟账户入口调整。
- 补齐之前未纳入 Git 的客服 UTF-8 手工迁移；新增四个活动字段的幂等迁移。

## 明确排除
租户控制台、TenantContext/实体隔离/策略、租户出站限制、租户私有文件路径、在线用户页面跟踪、多租户迁移及其测试均不提交。混合文件按基线重新集成，非租户版本沿用既有鉴权与图片路径，不引入空壳租户服务。

## 验证
后端完整 Maven 测试及三端生产 Docker 构建通过。后台 Node 21、移动端 9、PC 58、分享图测试通过；活动弹窗两端用例通过。真实 Chrome 分享模板回归每端 608 次画布导出，覆盖全部模板、多语言切换及 PNG 下载，无页面错误。一次性 MySQL 5.7 验证活动迁移重复执行，保留历史金额及模板 JSON，自动投递默认关闭。环境依赖的原有测试仍有跳过，不作为生产压力测试通过。

## 发布顺序与回退
从 Git 提交导出源码，在新的发布目录构建。保存旧镜像、配置和全量数据库备份；暂停两套后端写入后，再备份并比对资金快照，分别对主库和 demo 库执行两份活动迁移。检查现有客服字符集，不重复无必要的转码。更新两套后端、三个前端，保留线上配置与上传卷，不改租户结构。验证健康、前端版本、API/WS 后切换 current 指针。失败时回到旧发布的镜像和配置；新增列保留，禁止恢复旧资金快照覆盖新业务。
