# 目标价格控盘 V4 算法说明

整理日期：2026-10-13  
依据：`C:/workspace/fx/705` 工作区当前源码。本文说明代码行为，未核对线上部署版本，未执行算法测试或修改实现。

## 1. 算法概览

当前后台新启动的目标价格控盘采用 **V4 稳定轨迹算法**。系统在启动前生成完整的逐秒价格序列，运行时按经过的整秒读取对应价格点。价格围绕起点到目标的直线参考轨迹双向波动，并在指定时长结束时精确到达目标。

算法同时约束单秒涨跌幅度、固定偏差带、局部与全局幅度均衡、价格精度和终点。它不是运行时每秒独立抽取一个价格，也不通过最后一秒突然补差来达到目标。

目标执行阶段读取预生成价格路径；原始行情的后续变化不直接改变这条路径。目标完成后的保持偏移和恢复行情由独立流程处理。

旧任务仍按保存的算法版本读取。当前 V4 后台入口在算法被禁用时拒绝启动，不自动退回旧算法。

## 2. 输入与起点选择

### 2.1 输入参数

| 参数 | 含义与范围 |
| --- | --- |
| 目标价格 `T` | 大于 0、小于 `10^16`，符合品种价格精度；后台请求目标价格最多 8 位小数 |
| 执行时长 `N` | 1–86400 秒，整数；属于请求范围，不代表每个时长都能生成合法路径 |
| 波动强度 `I` | 1–10，整数 |
| 价格精度 `p` | 品种配置的 0–8 位小数，最小价格跳动 `q = 10^(-p)` |
| 随机开关 | 控制入口的种子选择意图；当前异步启动存在第 7 节所述差异 |
| 单步幅度公式 | 默认 `base * intensity`，也可按品种保存自定义公式 |
| 偏差带模式 | `AUTO` 自动计算，或 `MANUAL` 手动百分比 |
| 手动偏差带百分比 `r` | 大于 0、不超过 100，最多 8 位小数 |
| 自动恢复参数 | 是否到期恢复、快速或渐进模式、恢复时长、强度、随机开关及历史替代选项 |

### 2.2 起点 `S`

起点由服务端读取，不由操作者手填：

1. 当前原始行情可用且展示价有效时，取当前控盘展示价。
2. 不满足上一条件时，取最近已完成 K 线的收盘价；已有混合分钟参与历史起点选择。
3. 没有可用已完成 K 线时，取最后有效报价。
4. 已有保持状态时，使用保持记录的最后展示价衔接。

没有有效正数起点时拒绝启动。预计算结束后，系统重新检查起点、品种配置版本、精度和前一任务身份；发生变化则拒绝使用过时计划，并要求刷新预览。

## 3. 每秒涨跌幅度

### 3.1 默认自适应公式

设绝对目标价差 `G = |T-S|`，`ceil_q(x)` 表示向上取整到合法价格刻度：

```text
基础幅度 B = ceil_q(max(
    S × 0.00001,
    G / max(1, N-2),
    10 × q
))

典型单秒绝对幅度 A = B × I
最小单秒幅度 = ceil_q(0.9 × A)
最大单秒幅度 = floor_q(1.1 × A)
```

三个基础项分别承担以下作用：

- `S × 0.00001`：按起点价格提供基础量级。
- `G / max(1,N-2)`：根据目标距离和执行时间增大幅度，并为反向步骤预留空间。
- `10q`：提供价格精度下限，避免默认幅度区间缺少足够的合法刻度。

强度是基础幅度的倍数，不是点数或百分比。强度增大时，单秒双向波动金额增大，指定结束时间不变。基础幅度计算只提供候选参数，不能代替完整路径验收。

### 3.2 自定义公式

自定义公式结果作为典型单秒幅度 `A`，仍使用其 90%–110% 作为合法单步区间。

可用变量：`base`、`start`、`target`、`gap`、`duration`、`intensity`、`tick`。支持 `+ - * /`、括号及 `abs/min/max`。公式结果必须大于 0、小于 `10^16`。

代码通过去除首尾空白后是否精确等于 `base * intensity` 来识别默认自适应分支。数学等价但文本不同的公式可能进入自定义分支，影响自动偏差带计算规则。

## 4. 固定偏差带

第 `t` 秒的直线参考价格为：

```text
L(t) = S + (T-S) × t/N
每个秒点必须满足：|P(t)-L(t)| ≤ C
```

`C` 为偏差带半宽，在任务创建时冻结，基准是起点价格，执行期间不随原始行情或当前展示价变化。

| 组合 | 半宽 `C` |
| --- | --- |
| 默认公式 + `AUTO` | `floor_q(min(4A,S))` |
| 自定义公式 + `AUTO` | `floor_q(S × (0.004I) / 100)` |
| `MANUAL`，输入百分比 `r` | `floor_q(S × r / 100)` |

自定义公式的自动百分比是强度 1 对应 **0.004%**，强度 10 对应 **0.04%**。默认公式的自动带宽按典型幅度推导，并以起点价格的 100% 封顶。

手动偏差带不会随强度自动扩大。向下取整后不足一个价格刻度时，系统拒绝该配置，不会偷偷放宽手动范围。

## 5. 完整路径生成

### 5.1 金额与方向分配

所有价格和金额先换算成整数 tick，使用整数计算保持精度。

系统先求可行的上涨次数 `u`、下跌次数 `d = N-u`，两者至少为 1；再分配两侧总金额，使：

```text
上涨总金额 U − 下跌总金额 D = 目标净价差
总绝对路程 V = U + D

U = (V + 目标净价差) / 2
D = (V − 目标净价差) / 2
```

整数刻度下还需满足奇偶条件、各步幅度上下限和全程平均幅度约束。金额池先分配余数、打乱顺序，再尝试受限的随机金额转移；这些操作保持两侧总金额不变。

### 5.2 逐秒选择

每秒根据剩余上涨次数和剩余秒数得到基础上涨概率，再加入最多约 5 个百分点的参考线反馈：价格高于参考线时降低上涨概率，低于参考线时反向调整。

候选步骤必须同时满足正价格、幅度区间、固定偏差带、滑动窗口与分段限制。优先尝试随机选出的方向，没有合法候选时再尝试反方向。

没有可行步骤时，系统允许有限回退：最多回退 64 秒，单轮最多 128 次回退。整体最多 32 轮、约 5 秒搜索预算；全进程最多两个并发生成槽位。

生成完成后执行独立的全量路径验收。未找到通过验收的路径时拒绝启动，不扩大既定幅度或偏差带，也不在运行时重新抽取路径。

### 5.3 硬约束与均衡指标

| 约束 | 验收要求 |
| --- | --- |
| 点数与端点 | 恰好 `N+1` 个点，`P(0)=S`，`P(N)=T` |
| 价格与精度 | 每个点大于 0、小于 `10^16`，符合品种刻度 |
| 单秒幅度 | 每步绝对涨跌在指定上下限内，不允许零变动 |
| 双向变化 | 至少一次上涨、一次下跌，不要求次数相等 |
| 全程均幅 | 平均绝对幅度处于单步区间中点的 ±3% 内 |
| 10 秒窗口 | 每个完整滑动窗口平均绝对幅度处于全程平均的 ±3% 内 |
| 30 秒窗口 | 同上；任务不足窗口长度时不检查该窗口 |
| 前中后三段 | 按 `floor(N/3)`、`floor(2N/3)` 切分；`N≥3` 时各段平均绝对幅度处于全程平均的 ±3% 内 |
| 偏差带 | 所有秒点均满足 `|P(t)-L(t)|≤C` |

这里的“均衡”指**绝对波动金额均衡**，不要求涨跌次数各半，也不要求每秒净推进相同。

一秒任务无法满足双向要求。更长任务是否可行，还取决于目标价差、精度、幅度、偏差带及整数约束。

## 6. 预览、执行与结束

### 6.1 预览与启动

档位表的快速可行性判断主要筛选参数、首步偏差带和金额分配；通过筛选不代表完整路径一定可生成。

完整预览会尝试生成并验收候选轨迹。后台启动使用异步命令流程：请求被接受后，后台准备路径，再校验并激活任务。HTTP 202 表示命令已接受，不等于任务已经成功运行。

预览候选仅供查看，启动时重新检查起点和配置；实际启动轨迹不承诺与预览逐点相同。

### 6.2 逐秒执行与持久化

运行时使用以下索引读取计划价格：

```text
索引 = floor((当前时间 − 启动时间) / 1000)
索引范围限制在 [0,N]
```

路径是整秒采样，不做秒内插值。完整参数、种子、价格序列、摘要和校验和存入数据库；恢复计划时重新检查参数、路径和校验和。

市场引擎持久化已发生的逐秒价格点，对外读取已提交进度。重启后沿原任务时间和原计划继续，并补推进已发生的样本。引擎进度落后时，展示和交易可用性由市场引擎的进度及报价校验共同判断。

### 6.3 到期、停止与恢复

未开启自动恢复时，目标到期进入保持状态。系统确定一个固定偏移，之后随有效原始行情变化：

```text
固定偏移 = 到期目标价 − 到期边界所采用的原始参考价
后续展示价 = 当前原始行情价 + 固定偏移
```

因此，到期后不会永久钉住目标价格。手动停止会保留停止时已提交的展示价格对应偏移。

开启自动恢复时，到期转入等待源行情或恢复状态。渐进恢复逐步消除偏移，终点是恢复结束时的原始行情价；快速恢复直接返回原始行情。恢复阶段缺少有效原始行情时等待或暂停，不消耗未观察到的恢复时间。恢复采用独立计算逻辑，不复用目标 V4 轨迹生成器。

控盘生成点和混合历史有持久化记录；历史替代选项决定何时发布源行情替代，不能沿用旧文档中“刷新不保留逐秒控盘走势”的描述。

## 7. 随机开关的当前实现差异

V4 纯算法 `generate(parameters, seed)` 始终使用带种子的随机生成器，本身没有关闭波动的分支。即使关闭随机，合法路径仍必须有涨、有跌。

入口目前存在两种行为：

| 入口 | 种子来源 |
| --- | --- |
| 预览或无命令种子的直接准备调用 | 开启随机时使用随机种子；关闭时使用参数快照的哈希种子 |
| 当前后台异步启动 | 接受命令时无条件生成随机种子，准备阶段优先使用这个命令种子 |

因此，**当前后台异步启动即使关闭随机，也可能每次生成不同排列**。同一命令保存的种子仍可用于重试和重放。

这是当前代码观察到的差异，本文没有修复它。关闭随机不能解释为匀速直线，也不能按当前异步接口保证不同启动命令产生相同排列。

## 8. 主要拒绝条件

| 错误码 | 含义 |
| --- | --- |
| `INVALID_PARAMETERS` | 价格、精度、时长、强度或偏差带参数非法 |
| `INVALID_FORMULA` | 公式不合法，或结果不在允许范围 |
| `AMPLITUDE_PRECISION_UNREPRESENTABLE` | 单步幅度区间没有合法整数刻度 |
| `CORRIDOR_PRECISION_UNREPRESENTABLE` | 偏差带不足一个价格刻度 |
| `TARGET_AMPLITUDE_INFEASIBLE` | 无法满足净价差、双向次数、均幅或整数分配条件 |
| `CORRIDOR_STEP_INFEASIBLE` | 首步正、负候选均无法进入偏差带 |
| `PLAN_COMPUTE_BUSY` | 轨迹生成并发槽位已满 |
| `PLAN_SEARCH_EXHAUSTED` | 有限搜索预算内没有找到满足全部约束的路径 |
| `PLAN_BUDGET_EXHAUSTED` | 计划内存预算不足 |
| `START_BASIS_CHANGED` | 预计算后起点、配置或任务身份发生变化 |
| `PLAN_CORRUPTED` | 恢复或验收时发现计划、参数或校验和不一致 |
| `ALGORITHM_DISABLED` | V4 目标轨迹入口被禁用 |

`PLAN_SEARCH_EXHAUSTED` 是有界搜索失败，不能解释为已经数学证明无解。参数筛选、完整生成和任务激活是不同阶段。

## 9. 参数计算示例

假设：

```text
起点 S = 100000
目标 T = 100900
时长 N = 300 秒
价格精度 p = 2，q = 0.01
强度 I = 5
默认公式，AUTO 偏差带
```

计算结果：

```text
价格基准项 = 100000 × 0.00001 = 1
目标推进项 = 900 / 298 ≈ 3.020134
精度下限项 = 10 × 0.01 = 0.10

基础幅度 B = 向上取整到 0.01 = 3.03
典型幅度 A = 3.03 × 5 = 15.15
合法最小幅度 = ceil_0.01(15.15 × 0.9) = 13.64
合法最大幅度 = floor_0.01(15.15 × 1.1) = 16.66
自动半宽 C = 4 × 15.15 = 60.60
对应半宽百分比 = 60.60 / 100000 × 100% = 0.0606%

参考线 L(t) = 100000 + 3t
```

每秒涨跌金额为 13.64–16.66，价格必须处于当秒参考线的 ±60.60 内；整条路径最终净上涨 900。每秒平均净推进 3 与每秒绝对波动约 15.15 是两个不同指标。

以上是参数手算，没有运行生成器；完整路径能否生成仍需实际验收。
