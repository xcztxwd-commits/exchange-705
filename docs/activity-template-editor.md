# 活动模板编辑器

## 需求与原有问题
原实现把活动文案保存在 translations，页面结构、背景、礼盒动画及部分标题、按钮、账户说明则写在 ActivityCenter.vue 和 utils/activity.ts 中。客户语言选择与活动文案回退分别执行，因此可能出现日文系统文字与英文正文并存。

新设计把封面 gift、详情 detail、成功 success 及自定义页面作为完整模板保存。每个语言版本保存独立页面树，缺失语言整页回退 defaultLocale。所有业务展示文字均来自树中的可编辑组件，不再插入旧版固定文案。关闭安全控件、接口错误及后端领取校验不属于营销模板。

## 使用
活动或模板编辑窗口选择语言，打开“可视化模板编辑器”。拖入容器、文字、图片/GIF、按钮或金额组件。双击文字或在组件文字栏编辑；右侧画笔调整尺寸、Flex 图文比例、字体、颜色、背景、边框、圆角、间距和定位。上传背景时先选择容器。GIF 保留动画，单文件最大 5MB。顶部可设置弹窗宽度、圆角、遮罩色与模糊。

首屏保留为入口，详情与成功页及自定义页可删除，可编辑全部组件；可新增并命名其他页面。按钮可跳转设计页、领取、关闭或跳转站内路径。成功页只有真实领取成功后显示，不允许通过普通跳转伪造到账。应用设计仅回填编辑窗口，仍需保存活动/模板才持久化。已有活动不自动转换，避免覆盖线上设计。

## 数据与安全
layout_json 保存版本化结构树，不保存原始可执行 HTML 或 JavaScript。Vue 使用文本节点和固定组件渲染；不使用 v-html。模板脚本、任意事件属性、CSS URL、跨租户私有图片、外部页面跳转不受支持。图片与背景通过受保护接口读取，blob 仅作会话预览，不写入模板。后端校验默认语言、页面引用、组件种类、样式、层级和总量（每种语言最多12页/500组件，JSON最多2MB）。

显示金额支持 {amount}，登录天数支持 {days}。金额、预算、领取次数、资格和到账结果仍由后端计算。后台不能通过样式改写资金状态。自定义动态效果使用 GIF；任意动画脚本、视频/Lottie、HTML源码导入不在本次范围。行内粗体、斜体、下划线和样式保存为安全文本片段；不保留任意HTML。

## 简化编辑器与素材库（2026-09-29）

- 左侧仅保留素材和图层，中间画布，右侧根据选择显示常用属性；页面、弹窗外观收进“页面设置”。隐藏开发者代码导出、通用 CSS 面板。
- 图片/GIF 上传后进入服务端素材库。库内素材可预览、拖入或点“添加”。选中任意组件（含嵌套 CSS 绘图及动画）可存入素材库。
- 内置闭合礼盒、打开礼盒和循环开盖动画。支持轻浮动、呼吸缩放；动画在素材库、预览、编辑画布、手机端和桌面端采用同一组固定关键帧，尊重系统减少动画设置。
- 不接收任意 CSS/JS 代码；CSS 绘图保存为安全组件树，动画保存为白名单标识。素材存储不会携带其他活动的页面跳转，保存时该类按钮重置为关闭。
- 拖动组件自由定位，拖动控制点缩放；右侧也可输入宽高/坐标，调节整体缩放、颜色、圆角、字号和层级。自由定位内容需要在目标手机/桌面尺寸预览，超出画布部分会裁切。
- 素材按租户保存、搜索和分页。只有有公告权限的管理员可访问其他管理员存入库中的素材；未发布素材不会对客户公开。移除为软删除，不删除图片文件，不影响已插入活动的独立副本。
- 发布需执行 `V2026092905__activity_material_library.sql` 并更新后端、后台、手机端、桌面端。本地构建不等于已部署。
- 回归：`PLAYWRIGHT_MODULE` 可指定已安装 Playwright 的绝对模块目录，启动后台开发服务 `127.0.0.1:5191` 后运行 `node scripts/test-activity-editor.cjs`。浏览器测试使用隔离接口夹具，不写线上活动。


## 按钮动作与页面预设（2026-09-29）

### 设计
复用现有组件树和活动接口，不引入通用流程引擎。按钮右侧显示顺序动作列表，支持添加、删除、上移、下移，最多 8 步。提供“确认已读”“已读并关闭”“领取并展示结果”快捷组合；旧按钮动作在编辑时自动转换。

### 可绑定动作
- 标记已读：POST `/activity/messages/{当前消息}/event`，固定事件 OPENED。
- 领取体验金：POST `/activity/messages/{当前消息}/claim`，金额、当前用户与幂等性由服务器决定。同一按钮只能绑定一次领取。
- 指定页面、下一页、上一页、站内路径、关闭弹窗。跳转和关闭只能是最后一步，避免跳转后仍有后台副作用。下一页/上一页在未领取时跳过成功页。
- 多个接口按列表顺序等待完成，任一步失败立即停止并显示错误；成功的前序请求不回滚。重试不会重复入账。执行期间阻止重复点击，关闭或切换会话后停止后续动作。
- 成功页必须在领取成功后进入。纯视觉预览使用模拟回调并显示执行记录，不发送真实领取或已读请求。

仅支持注册的业务接口，不允许模板输入任意 URL、认证信息、金额或用户 ID。后端验证动作白名单、数量、顺序、页面引用及站内路径；新增业务接口应同时增加固定客户端适配器及后端白名单。

### 页面预设
“新增页面”和“页面设置 / 页面预设”提供礼盒首屏、公告详情、领取成功、图片海报和空白画布。可先预览再应用；替换当前页需要确认，其他页面不变。领取成功页最多一个。可选页面被删除后，相关按钮跳转改为关闭；重新添加礼盒预设也不会留下失效页面引用。

运行 `node scripts/test-activity-actions.cjs`、`node scripts/test-activity-popup.cjs` 和浏览器回归脚本。动作仍存于 layout_json，不需要新增数据库列；需同步发布后端与三端资源，避免旧客户端忽略多步骤动作。本次源码备份位于 `rollback/activity-button-flows-20260929`。
