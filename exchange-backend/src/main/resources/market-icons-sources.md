# Market icon resources

The adjacent market-icons.zip is generated by docker/vendor-market-icons.py. SVG files and upstream licenses are retained in the archive. No third-party image URL is requested at runtime.

## Binance official asset logos (preferred for crypto)

`binance-market-icons.zip` is generated by `python docker/vendor-binance-icons.py --container` (omit `--container` when the host can reach Binance directly). It overlays the community crypto icons below without changing forex, stock or other icons. PNG/JPEG/WebP images from Binance's CDN are embedded in standalone SVGs; browsers load them from this application, not Binance. Existing manually configured external/uploaded icon URLs are unchanged.

Source: [Binance public asset directory](https://www.binance.com/bapi/asset/v2/public/asset/asset/get-all-asset), using exact `assetCode` and `logoUrl` fields. Only `bin.bnbstatic.com` and `ex.bnbstatic.com` HTTPS image URLs are accepted. The archive's `sources.json` records each asset ID, name, upstream URL, image SHA-256, fetch time, and full coverage/missing lists. These are Binance-hosted asset brand images, not the Binance exchange logo and not CC0; trademarks remain with their respective owners.

2026-09-22 snapshot: 513 distinct asset logos (512 PNG, 1 JPEG), 2,630,204-byte archive. Against live exchangeInfo, exact matches cover 492/494 spot base assets (1,364/1,370 trading pairs) and 376/526 crypto perpetual base assets (415/569 pairs). The two unmatched spot assets have non-ASCII codes unsupported by the current catalog. Unmatched futures include futures-only assets and multiplier codes such as `1000PEPE`; no prefix stripping or guessed identity mapping is applied. Missing Binance logos retain the community icon or labeled badge fallback. This snapshot does not claim full futures, commodity, delivery-contract or options coverage.

New crypto icon URLs use `?v=2` to invalidate the old seven-day browser cache. No existing Binance instruments were present in the running database at deployment, so no existing icon URL migration was needed. Refresh the archive with the command above and rebuild the backend to incorporate later Binance assets; this is a bundled snapshot, not runtime synchronization.

- Cryptocurrency Icons 0.18.1: https://github.com/spothq/cryptocurrency-icons — CC0.
- Web3 Icons core 4.0.56: https://github.com/0xa3k5/web3icons — MIT. Preferred where a ticker exists in both sets. License pinned to npm gitHead f6881ce9606c86103cceac250b01df3f8867620d.
- Flag Icons 7.3.2: https://github.com/lipis/flag-icons — MIT. Currency-to-country mappings are explicit; EUR uses the EU flag. Unmapped currencies display their code.
- Simple Icons 11.15.0: https://github.com/simple-icons/simple-icons — CC0. Only the explicitly mapped stock-company SVGs are included. Brand trademarks remain with their holders.

There is no claim of full exchange or Yahoo global coverage. Binance exchangeInfo and the tested Yahoo lookup response do not supply an image field; Binance logos instead come from the separate asset directory above. Stocks outside the curated mappings, unknown tokens and indices/commodities receive a generated, labeled SVG badge, not a claimed official logo. An administrator can replace iconUrl using the existing editor.

The archive contains 2,064 crypto SVGs, 271 flags and 26 mapped stock-company SVGs. A 2026-09-22 comparison against Binance spot found ticker SVG matches for 237 of 494 active base assets; the rest use code badges. Symbol tickers may be reused by unrelated assets: mappings should be checked against issuer identity before expanding coverage. The current JPY=X instrument is explicitly mapped to USD/JPY flags.
