# Market icon resources

The adjacent market-icons.zip is generated by docker/vendor-market-icons.py. SVG files and upstream licenses are retained in the archive. No third-party image URL is requested at runtime.

- Cryptocurrency Icons 0.18.1: https://github.com/spothq/cryptocurrency-icons — CC0.
- Web3 Icons core 4.0.56: https://github.com/0xa3k5/web3icons — MIT. Preferred where a ticker exists in both sets. License pinned to npm gitHead f6881ce9606c86103cceac250b01df3f8867620d.
- Flag Icons 7.3.2: https://github.com/lipis/flag-icons — MIT. Currency-to-country mappings are explicit; EUR uses the EU flag. Unmapped currencies display their code.
- Simple Icons 11.15.0: https://github.com/simple-icons/simple-icons — CC0. Only the explicitly mapped stock-company SVGs are included. Brand trademarks remain with their holders.

There is no claim of full exchange or Yahoo global coverage. Binance exchangeInfo and the tested Yahoo lookup response do not supply an image field. Stocks outside the curated mappings, unknown tokens and indices/commodities receive a generated, labeled SVG badge, not a claimed official logo. An administrator can replace iconUrl using the existing editor.

The archive contains 2,064 crypto SVGs, 271 flags and 26 mapped stock-company SVGs. A 2026-09-22 comparison against Binance spot found ticker SVG matches for 237 of 494 active base assets; the rest use code badges. Symbol tickers may be reused by unrelated assets: mappings should be checked against issuer identity before expanding coverage. The current JPY=X instrument is explicitly mapped to USD/JPY flags.
